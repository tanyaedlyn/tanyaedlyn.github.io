# Tanya Edlyn UX Portfolio

This is a self-contained static portfolio website. The main page is `index.html`; its CSS and JavaScript are included inline, so no build tools or package installation are required.

## Folder structure

```text
tanya-portfolio-project/
├── index.html
├── assets/
│   └── Surge_Case_Study.png
└── README.md
```

## Run locally

Open `index.html` directly in a browser, or open this folder in VS Code and use any static server extension. The Surge project detail page expects the image at `assets/Surge_Case_Study.png`.

## Add more images

Place additional images in `assets/` or a subfolder such as `assets/photography/`, then update the relevant HTML `src` or JavaScript `images` path. Keep the path and capitalization exactly the same as the filename.

## Publish

For GitHub Pages, upload the complete project folder contents to a repository, keep `index.html` at the repository root, and enable Pages from the `main` branch and the `/ (root)` folder.
